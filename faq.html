Frequently Asked Questions.

Everything you need to know about Aura AI, Groq inference speeds, and hosting configuration.

Is Aura AI completely free to use? +
Yes! Aura AI is 100% free and open-source. There are no paid tiers, hidden subscriptions, or token charges. You can use the public studio or deploy your own copy to Surge.sh for zero hosting costs.
How does the Groq API proxy protect my keys? +
The frontend running on Surge.sh never holds your GROQ_API_KEY. Instead, user requests are sent directly to a lightweight Vercel serverless function (`/api/chat.js`) which securely attaches the API token in secret headers before querying Groq's servers.
Which AI models are supported? +
Aura AI supports high-speed open-source flagship models served via Groq, including LLaMA 3.3 70B Versatile, DeepSeek-R1 Distill LLaMA 70B, and Mixtral 8x7B.
Can I host my own version on Surge.sh? +
Absolutely! Just clone the project repository, configure your Vercel serverless environment variable, and run npx surge . your-domain.surge.sh in your terminal. Setup takes less than two minutes.
