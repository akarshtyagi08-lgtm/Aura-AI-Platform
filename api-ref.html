API Endpoint Documentation.

Complete payload definitions and code examples for interacting with our backend proxy endpoints.

POST /api/chat

Dispatches user prompt messages to Groq LPU inference models via serverless proxy handler.

Request Body Parameters

Field Type Required Description
prompt string Yes User input prompt string.
model string No Target LLM identifier (defaults to llama-3.3-70b-versatile).
temperature number No Sampling randomness (0.0 to 1.0). Default: 0.7

cURL Example

curl -X POST https://aura-ai-platform.surge.sh/api/chat \ -H "Content-Type: application/json" \ -d '{ "prompt": "Write a Python script for exponential backoff", "model": "llama-3.3-70b-versatile", "temperature": 0.5 }'

JSON Response Format

{ "status": "success", "model": "llama-3.3-70b-versatile", "reply": "Here is a clean Python script utilizing standard time module...", "usage": { "completion_tokens": 142, "prompt_tokens": 28, "total_tokens": 170 } }
