Architecture Overview

Aura AI is built using a modern decoupled architecture. The static frontend is served globally via Surge.sh CDN, while backend API requests are securely routed through a lightweight Vercel serverless proxy to Groq's LPU inference engine.

[ Surge.sh Frontend ] ---> [ Vercel Serverless Proxy ] ---> [ Groq API ]

Quickstart Setup

To run or customize Aura AI locally on your machine, clone the repository or open the project folder and start a static local server:

# Navigate to project directory cd aura-ai-platform # Serve locally using npx npx serve .

Vercel Proxy Setup

To prevent exposing your GROQ_API_KEY on the client side, create a serverless endpoint inside /api/chat.js deployed on Vercel:

export default async function handler(req, res) { const { prompt } = req.body; const response = await fetch("https://api.groq.com/openai/v1/chat/completions", { method: "POST", headers: { "Authorization": `Bearer ${process.env.GROQ_API_KEY}`, "Content-Type": "application/json" }, body: JSON.stringify({ model: "llama-3.3-70b-versatile", messages: [{ role: "user", content: prompt }] }) }); const data = await response.json(); res.status(200).json({ reply: data.choices[0].message.content }); }

Surge.sh Deployment

Deploying the static assets to Surge takes less than 10 seconds using the Surge CLI:

# Install Surge globally npm install -g surge # Deploy current directory surge . aura-ai-platform.surge.sh
